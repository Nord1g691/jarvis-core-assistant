# jarvis-core-assistant
JARVIS Core Assistant — An intelligent, voice-controlled web interface for Home Assistant, with dynamic cards, AI-powered actions, memory, automation, energy monitoring, cameras, media and more.

## V9
V9 is now published on `main` as an additive layer over the existing visual HUD/Core. The V9 base includes dynamic Home Assistant entity discovery, category/state presentation, manual selection, settings/layout state, contextual request routing, guarded action execution, self-test tooling, and the real connection/test surface.

The existing visual layer is preserved; V9 supplies data, actions and events around it. Test the integrated surface at `v9-test.html`.
